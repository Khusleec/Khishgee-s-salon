# Khishgee's Salon — үс, хумсны бүтээгдэхүүний онлайн дэлгүүр

Монголын зах зээлд зориулсан бүрэн ажиллагаатай е-худалдааны систем. Хэрэглэгчийн дэлгүүр
болон ажилтны админ самбар хоёулаа монгол хэлээр, ₮ валютаар ажиллана.

> **Гар утас нэгдүгээрт.** Үйлчлүүлэгчид голчлон утаснаас ханддаг тул дэлгүүрийн
> дизайн, урсгал бүхэн утсанд зориулж хийгдсэн — том дэлгэц нь өргөтгөл нь юм.

**Гадаад ажиллагааны сан ашиглаагүй** — Node.js-ийн дотоод модулиуд (`node:http`, `node:sqlite`,
`node:crypto`, `node:zlib`) дээр бүтсэн. Код бүхэлдээ **TypeScript**: сервер Node-ийн
төрөл хасагч (type stripping)-аар `.ts` файлыг шууд ажиллуулна, харин хөтчийн скриптүүд
(`src/client/`) `tsc`-ээр `public/` руу хөрвүүлэгдэнэ — тиймээс `typescript`-ийг татахын
тулд нэг удаа `npm install` хийнэ.

```bash

npm start       # эхлэхдээ хөтчийн скриптүүдийг автоматаар build хийнэ
```

| Хаяг | Тайлбар |

## Гар утасны туршлага

Дэлгүүр нь **PWA** — Chrome/Safari дээр «Нүүр дэлгэцэд нэмэх» гэж сонговол
жинхэнэ апп шиг бүтэн дэлгэцээр нээгдэнэ.

| Хэсэг | Утсанд зориулсан шийдэл |
| --- | --- |
| Толгой | Нэг мөр: лого + хайлт + сагс. Оролтын фонт 16px — iOS дээр фокуслахад дэлгэц томрохгүй |
| Доод цэс | Нүүр · Каталог · **Сагс (тоогоор)** · Хадгалсан · Профайл |
| Нүүр | Богино hero, хэвтээ гүйдэг ангилал ба «эрэлттэй» эгнээ |
| Каталог | Наалдмал **Шүүлтүүр / Эрэмбэ** мөр, идэвхтэй шүүлтүүрийн тоо, ангиллын хэвтээ чипс |
| Шүүлтүүр | Доод хуудас (bottom sheet) — «Цэвэрлэх» / «Үр дүнг харах» |
| Барааны хуудас | Дэлгэцийн доод хэсэгт **байнга харагдах** ширхэг + «Сагсанд · үнэ» мөр |
| Сагс | Бүтэн дэлгэцийн самбар; бараа нэмэхэд самбар автоматаар нээгдэхгүй (зөвхөн мэдэгдэнэ) |
| Захиалга | Дээр нь эвхэгддэг хураангуй, доор нь наалдмал «Төлөх дүн + Захиалах» мөр |
| Талбарууд | `type="tel"`, `inputmode="numeric"`, `autocomplete` — утасны гар шууд тохирно |
| Холбоо барих | Хөвөгч товч → **Утсаар залгах · Messenger · Захиалга шалгах** |
| Сүлжээ | Service worker — сул сүлжээнд шаардлагатай файлыг кэшээс өгнө |

Бүх хуудас 360 / 390 / 430px өргөнд **хэвтээ гүйлтгүй**, товчлуурын хэмжээ хуруунд тохирсон.

### Зочны захиалга

Утаснаас захиалдаг хүн ихэвчлэн бүртгэл үүсгэдэггүй. Тиймээс захиалга өгсний дараа
дугаар + утсыг зөвхөн тухайн төхөөрөмж дээр (`localStorage`) хадгалж,
баталгаажуулах хуудсыг дараа нь дахин нээх боломжтой болгосон. «Захиалга шалгах»
хуудсанд тухайн утаснаас хийсэн сүүлийн захиалгууд жагсаана. Сервер тал нь
захиалгын дугаар + утас хоёрыг үргэлж шалгасаар байна.

## Хэрэглэгчийн тал

- **Нүүр** — hero, ангилал, эрэлттэй ба шинэ бараа, урамшууллын баннер
- **Каталог** — төрөл / ангилал / брэнд / үнийн шүүлтүүр, 6 эрэмбэлэлт, хуудаслалт
- **Хайлт** — нэр, брэнд, SKU, тайлбараар
- **Барааны хуудас** — таб (дэлгэрэнгүй / заавар / найрлага / сэтгэгдэл), төстэй бараа, сэтгэгдэл бичих
- **Сагс** — хажуу самбар + бүтэн хуудас, `localStorage`-д хадгална
- **Захиалга** — 3 хүргэлтийн сонголт (хот / өөрөө авах / орон нутаг),
  3 төлбөрийн хэлбэр (бэлэн / данс / QPay), урамшууллын код
- **QPay төлбөр** — захиалгын хуудсан дээр QR код, банкны аппын холбоос, 5 сек тутам автомат шалгалт, төлөгдмөгц захиалга баталгаажна
- **Захиалга хянах** — дугаар + утсаар, 5 үе шаттай төлөвийн заалт
- **Хэрэглэгч** — бүртгэл, нэвтрэлт, **нууц үг сэргээх (SMS код)**, профайл, захиалгын түүх
- **SMS мэдэгдэл** — захиалга үүсэхэд, төлөв солигдоход, төлбөр орсонд
- **Хадгалсан бараа**, **Тусламж** (FAQ), **Бидний тухай**

## Админ самбар

- **Хяналтын самбар** — орлого / захиалга / хэрэглэгч / бараа, борлуулалтын график,
  төлөвийн задаргаа, эрэлттэй бараа, үлдэгдэл багатай, ангиллын орлого
- **Захиалга** — төлөвөөр шүүх, хайх, мөрөн дээрээс төлөв солих, дэлгэрэнгүй самбар
- **Бараа** — нэмэх / засах / устгах, хүснэгтээс шууд үлдэгдэл засах, зургийн өнгө ба хэлбэр,
  **жинхэнэ гэрэл зураг** байршуулах (чирж тавих, олон зураг, үндсэн зураг сонгох)
- **Төлбөр** — QPay нэхэмжлэх, төлөлтийн түүх, туршилт/live горим
- **Мессеж** — илгээсэн бүх SMS-ийн бүртгэл, туршилтын SMS илгээх
- **Тайлан** — захиалга / өдрийн борлуулалт / бараа / хэрэглэгч CSV (Excel-д шууд нээгдэнэ, огноо-төлөвөөр шүүх)
- **Холболт** — QPay, SMS-ийг хэрхэн идэвхжүүлэх заавар, одоогийн төлөв
- **Ангилал**, **Урамшууллын код**, **Хэрэглэгч**, **Тохиргоо**

### Админ самбар утсанд

Дэлгүүрийн эзэн ажлын байрандаа биш байхдаа ч захиалгаа удирдах шаардлагатай тул
админ хэсэг ч утсанд бүрэн ажиллана:

| Хэсэг | Утсанд |
| --- | --- |
| Навигац | Доод таб: **Самбар · Захиалга (шинэ захиалгын тоо) · Бараа · Цэс** |
| Хүснэгтүүд | Бүх хүснэгт **карт болж хувирна** — гарчиг дээрээ, талбар бүр шошготой |
| Захиалга | Карт дээрээс шууд төлөв солино; утасны дугаар дарахад залгана |
| Бараа | Картаас шууд үлдэгдэл засах, Засах / Устгах товч бүтэн өргөнөөр |
| Засварын форм | Бүтэн дэлгэцийн sheet, доод талд наалдмал Болих / Хадгалах |
| График | Утсанд 7 хоногийн багана, бичиг уншигдахуйц хэмжээтэй |
| Статистик | 2 баганаар эмхлэгдэнэ |

Хүснэгт → карт хувиргалт нь `data-label` шинж дээр суурилсан тул шинэ багана
нэмэхэд автоматаар дагаж ажиллана.

### Аюулгүй байдал

- Нууц үгийг **scrypt**-ээр давсалж хадгална
- Сешн токен нь `HttpOnly` + `SameSite=Lax` cookie, 30 хоногийн хугацаатай
- **Захиалгын үнийг үргэлж сервер тал дахин тооцно** — клиентээс ирсэн үнэ, нийт дүнг хүлээж авахгүй
- Үлдэгдлийг гүйлгээ дотор хасна; захиалга цуцлахад буцаан нэмнэ
- Бүх админ endpoint эрхийн шалгалттай; SQL бүхэлдээ параметртэй query
- Статик файл сервелэхэд зам гарах (path traversal) хамгаалалттай

### Зураг

Гадаад зураг, CDN ашиглаагүй. Бараа бүрийн `hue` (0–360) ба `shape` утгаас сервер дээр
SVG зураг үүснэ (`/img/p/:id.svg`). PWA дүрсийг мөн кодоор PNG болгон зурдаг
(`/icons/icon-192.png`) тул зургийн файл огт хадгалахгүй.

## Гадаад холболт (QPay, SMS)

Систем **түлхүүргүйгээр бүрэн ажиллана** — QPay болон SMS «туршилтын горимд» (mock)
байна: нэхэмжлэх дотооддоо үүсч, QR зурагдаж, «Төлсөн мэт болгох» товчоор урсгалыг
бүтнээр нь турших боломжтой; SMS нь серверийн консол болон админы «Мессеж» хуудсанд
бүртгэгдэнэ. Жинхэнэ түлхүүрээ `.env`-д бичихэд **код өөрчлөхгүйгээр** live болно.

```bash
cp .env.example .env     # дараа нь утгуудаа бөглөнө
npm start                # эхлэхэд "QPay : live / SMS : live" гэж харагдана
```

| Хувьсагч | Тайлбар |
| --- | --- |
| `QPAY_USERNAME` `QPAY_PASSWORD` `QPAY_INVOICE_CODE` | QPay мерчант гэрээнээс. Гурвуулаа байвал live |
| `PUBLIC_BASE_URL` | Интернэтэд харагдах хаяг — QPay callback ирүүлнэ |
| `SMS_PROVIDER` | `mock` (анхдагч) · `http` (Монголын оператор/агрегаторын API) · `twilio` |
| `SMS_HTTP_URL` + `SMS_HTTP_QUERY` / `SMS_HTTP_BODY` | `{to}` `{text}` `{from}` орлуулагчтай ерөнхий HTTP gateway |
| `RESET_REVEAL_IN_MOCK` | SMS mock үед сэргээх кодыг хариунд буцаах эсэх (зөвхөн хөгжүүлэлтэд) |

Бүх хувьсагчийн тайлбар `.env.example` дотор, мөн админы **Холболт** хуудсанд байна.

### QPay урсгал

1. Хэрэглэгч захиалга өгөхдөө «QPay / картаар» сонгоно
2. Захиалгын хуудсан дээр `POST /api/payments/qpay/:code` → QR код + банкны аппын холбоосууд
3. Хуудас 5 секунд тутам `GET /api/payments/qpay/:code` дуудаж шалгана;
   QPay мөн `PUBLIC_BASE_URL/api/payments/qpay-callback` руу мэдэгдэнэ
4. Төлөгдмөгц `orders.payment_status = paid`, захиалга автоматаар «Баталгаажсан» болж, SMS явна

### Аюулгүй байдлын нэмэлт

- Нууц үг сэргээх код **SHA-256**-аар хадгалагдана, 15 минут хүчинтэй, 5 буруу оролдлогоор хаагдана,
  1 минутад 1 хүсэлт; амжилттай сэргээхэд бүх хуучин сешн устна; бүртгэлгүй дугаарт ч ижил хариу
  (дугаар тандах боломжгүй)
- Зураг байршуулахад өргөтгөлд итгэхгүй — **эхний байтуудаас** жинхэнэ төрлийг тогтооно;
  файлын нэр санамсаргүй, зам гарах боломжгүй
- QPay callback-д шууд итгэхгүй — QPay-аас **дахин лавлаж** байж төлөгдсөн гэж тэмдэглэнэ;
  QPay live үед mock-ын «simulate» endpoint хаалттай
- CSV-д `=` `+` `-` `@`-аар эхэлсэн нүдийг хамгаална (Excel томьёо тарилга)

### Тест

## Дараагийн алхмууд (санал)

- Имэйлээр захиалгын баримт илгээх
- Барааны зургийг автоматаар жижигрүүлэх (thumbnail) — одоо эх хэмжээгээр хадгална
- Олон админ / ажилтны эрхийн түвшин
- Захиалгыг хэрэглэгч өөрөө цуцлах (тодорхой хугацаанд)
